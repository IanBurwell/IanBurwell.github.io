As I noted in my goals, the hardest challenge of this project is ultimately not technical, but behavioral. The website needs content, and I do not want to take the lazy approach of having AI churn out articles. This means I obviously need to create more content. But as much as I want to be, I am not a content creator (yet). To be able to become the self-identifying content creator this website needs, I need to build some values and habits.



I need to be consistent with creating new content. This means the website needs to not only house content, but it needs to be built to actively encourage building me a habit of creating content.  

 
Creating content is not something I can just come home from work every day and magically start doing. I need to build up many more habits if I want to become someone who creates content. Thus, I will plan for this website to encourage the following four of James' laws to ideally build a habit of creating content.
